Continuação do Cedro Plus. O Google Meet já está funcionando (GoogleMeetService, endpoint
/api/sessoes/{id}/link-reuniao). Agora vamos remover completamente o Agora.io de todo o
projeto (backend, mobile e web), já que as chamadas de voz/vídeo passam a ser feitas via
Google Meet.

=== PARTE 1 — BACKEND: remover Agora ===

1. Deletar:
   - controller/AgoraController.java
   - controller/ChamadaController.java
   - service/AgoraService.java
   - service/ChamadaService.java
   - Qualquer DTO usado exclusivamente por eles (ex: AgoraTokenRequest/Response)

2. Remover do pom.xml a dependência io.agora:authentication

3. Remover de application.properties: AGORA_APP_ID, AGORA_APP_CERTIFICATE

4. Na tabela `chamadas_historico`: manter a tabela por enquanto (histórico existente não
   deve ser apagado), mas remover qualquer código Java que dependa dela para novas chamadas
   Agora. Se não houver mais nenhum uso, deixar um comentário no service indicando que a
   tabela ficou legada.

5. Repensar o limite de uso gratuito: como o Meet não tem custo por minuto, substituir a
   lógica de "10 chamadas/mês grátis" por "N sessões agendadas/mês no plano gratuito"
   (reaproveitar a mesma tabela de assinaturas). Criar constante
   LIMITE_SESSOES_GRATIS_MES = 4 (ajustável) e aplicar a verificação no SessaoService,
   no método de criação de sessão, retornando 403 com mensagem clara se o paciente free
   já atingiu o limite no mês corrente.

=== PARTE 2 — MOBILE: remover Agora e usar o Meet ===

1. Desinstalar: npm uninstall react-native-agora

2. Deletar/renomear:
   - services/callService.ts → pode ser reaproveitado, mas remover toda lógica de token
     Agora; manter só a chamada para GET /api/sessoes/{id}/link-reuniao
   - screens/calls/VoiceCallScreen.tsx e VideoCallScreen.tsx (+ versões .web.tsx):
     substituir por uma única tela ReuniaoScreen.tsx

3. ReuniaoScreen.tsx deve:
   - Receber sessaoId via params de navegação
   - Chamar GET /api/sessoes/{id}/link-reuniao a cada X segundos (polling, ex: 15s) até
     liberado=true
   - Enquanto liberado=false: mostrar contagem regressiva até o horário
     (usar o campo disponivelEm da resposta)
   - Quando liberado=true e link presente: mostrar botão "Entrar na reunião" que abre o
     link via Linking.openURL (abre app do Meet nativo se instalado, senão navegador)
   - Se liberado=true e link=null (falha na geração): mostrar mensagem de erro amigável
     "Não foi possível gerar o link, contate o suporte"

4. Atualizar RootNavigator.tsx: trocar as rotas/modais de VoiceCallScreen/VideoCallScreen
   pela nova ReuniaoScreen

5. Atualizar todos os pontos que chamavam callService com lógica Agora (ex: dentro do
   ChatScreen, botão de iniciar chamada) para navegar até ReuniaoScreen passando o sessaoId
   correspondente, em vez de iniciar uma chamada Agora direto

6. Remover do types/api.types.ts qualquer tipo relacionado a token Agora

=== PARTE 3 — WEB: aplicar o mesmo padrão ===
